# HyAPI

HyAPI is a typed HTTP module library. The `hyapi` package provides declarative routes over an application-owned InferDI container; Elysia is an internal router. The repository includes a private PostgreSQL-backed [ERP example](apps/example/src/app.ts). Version 0.5.0 is unreleased; local builds and tarballs do not establish npm publication.

See [CONTRIBUTING.md](CONTRIBUTING.md) for development and release directions, [SECURITY.md](SECURITY.md) for private vulnerability reporting, and the [changelog](CHANGELOG.md) for release status.

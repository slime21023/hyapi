# Migrating to v0.7.0

v0.7.0 focuses on a lower-cognitive-load development experience.

## Configuration defaults

Use `defineConfig` when only the application name is needed:

```ts
import { defineConfig } from "@hyapi/core";

const config = defineConfig({ name: "orders-api" });
```

Existing complete `AppConfig` objects remain supported.

## Module dependencies

Rename the startup ordering field:

```diff
 defineModule({
   name: "orders",
-  imports: ["users"],
+  dependencies: ["users"],
 });
```

`imports` is removed because it is easily confused with TypeScript imports.

## CLI diagnostics

`doctor()` now returns structured diagnostics. The CLI supports `--json` for CI and tooling:

```bash
hyapi doctor --json
```

Boundary inspection is intentionally marked as `analysisMode: "heuristic"`.

# Extract a HyAPI module over HTTP

HyAPI v0.5 lets a module move from the same process to an HTTP service without changing the
consumer's business use cases. The consumer continues to depend on a typed Port; only application
composition changes from `providePort()` to `provideHttp()`.

## 1. Keep the business Port neutral

Put the capability in a shared contracts package, not in either module directory:

```ts
export interface UserDirectory {
  find(id: string): Promise<{ id: string; name: string } | null>;
}

export const userDirectory = definePort<UserDirectory>("users.directory");
```

Orders continues to use `module.use(userDirectory)`. Its use cases do not know whether the provider
is local or remote.

## 2. Define the HTTP contract once

The extracted service and its client share route paths, TypeBox schemas, response statuses, and
OpenAPI metadata:

```ts
export const usersHttp = defineHttpContract({
  name: "users.directory",
  version: 1,
  routes: {
    find: {
      method: "get",
      path: "/v1/users/{id}",
      request: { params: Type.Object({ id: Type.String() }) },
      responses: {
        200: Type.Object({ id: Type.String(), name: Type.String() }),
        404: Type.Null(),
      },
    },
  },
});
```

The Users service publishes it with `registerHttpContract(module, usersHttp, handlers)`. This
creates regular HyAPI routes, so generated OpenAPI remains the source-of-truth service document.

## 3. Change only application composition

Before extraction, the modular monolith supplies a local adapter:

```ts
providers: [providePort(userDirectory, localUserDirectory)];
```

After extraction, replace it with a remote adapter. The Orders module and its routes stay intact:

```ts
providers: [provideHttp(userDirectory, {
  contract: usersHttp,
  baseUrl: "https://users.internal.example",
  timeoutMs: 800,
  retry: { maxAttempts: 2, delayMs: 25 },
  adapt: (client) => ({
    find: async (id) => {
      const response = await client.find({ params: { id } });
      return response.status === 404 ? null : response.body;
    },
  }),
})];
```

`provideHttp()` rejects a contract whose name or version differs from the Port before the
application accepts requests. Reuse the same `definePortContract()` suite for local, fake, and
remote providers.

## Operational behavior

- `timeoutMs` is required for every typed HTTP client.
- `get`, `put`, `delete`, and `options` may retry network, timeout, and undeclared 5xx failures.
- `post` and `patch` retry only when the caller supplies an `idempotency-key` header.
- Undeclared 4xx, 5xx, network, timeout, and invalid-response failures are distinguished through
  `HttpContractClientError.reason`.
- For direct typed-client calls from a route, pass
  `withHttpContext({ request, requestId }, "orders")` as the request init to propagate correlation
  ID, W3C `traceparent`, and caller service identity.

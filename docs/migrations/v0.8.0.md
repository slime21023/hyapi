# Migrating to v0.8.0

v0.8 adds provider lifecycle management and major/minor contract compatibility.

## Contract versions

Contracts declare a major/minor version:

```ts
const users = definePort<UserDirectory>("users.directory", { major: 1, minor: 2 });
```

A provider is compatible when its major version matches and its minor version is equal to or newer
than the required minor version.

## Provider lifecycle

Providers may expose `connect` and `close` callbacks through `providePort()`. Connection callbacks
run before the application becomes ready, and all close callbacks are attempted during shutdown.
Health checks are application-level probes registered through `healthChecks`.

HTTP readiness endpoints can be registered independently of their providers:

```ts
createApplication({
  // providers: [provideHttp(...)],
  healthChecks: [createHttpHealthCheck({
    name: "users-service",
    baseUrl: "http://users-service",
    timeoutMs: 1000,
    path: "/health/ready",
  })],
});
```

This keeps provider lifecycle and operational readiness independent.

# Migrating to v0.8.0

v0.8 adds provider lifecycle management and major/minor contract compatibility.

## Contract versions

Numeric versions remain valid and mean `{ major: n, minor: 0 }`. New contracts may declare:

```ts
const users = definePort<UserDirectory>("users.directory", { major: 1, minor: 2 });
```

A provider is compatible when its major version matches and its minor version is equal to or newer
than the required minor version.

## Provider lifecycle

Providers may expose `connect`, `health`, and `close` callbacks through `providePort()`. Connection
callbacks run before the application becomes ready. `app.health()` reports provider status, and all
close callbacks are attempted during shutdown.

HTTP providers may opt into a remote health endpoint:

```ts
provideHttp(usersPort, {
  contract: usersContract,
  baseUrl: "http://users-service",
  timeoutMs: 1000,
  healthPath: "/health/ready",
  adapt: (client) => client,
});
```

Without `healthPath`, an HTTP provider reports healthy without an extra network request.

# Quickstart

`hyapi@0.5.0` is unreleased. Use a checkout of this repository rather than `bun add hyapi`:

```sh
git clone https://github.com/slime21023/hyapi.git
cd hyapi
```

The following Quickstart is maintained in the repository [README](https://github.com/slime21023/hyapi/blob/main/README.md) and requires no database. Bun 1.4.0 and Node 24+ are prerequisites.
